# 04. 튜터 피드백 & KPT 회고

> 출처: 팀 노션 페이지("서면 피드백", "KPT 회고") 원문을 그대로 옮겼습니다.

## 메인 튜터 피드백 — 임영재 튜터

**1. 데이터 EDA 및 전처리**
- 전처리 시 의료적으로 유의미한 값(이상치가 아닌 실제 질병 수치)까지 제거할
  위험이 있으므로, IQR 방식을 쓸 경우 전처리 전후 데이터를 비교해 왜곡
  여부를 확인해야 함
- 새로운 전처리 방식을 고안해보는 것도 방법

**2. 결과 해석 및 보고**
- 고BMI와 흡연 변수가 결합했을 때, 구체적으로 어떤 건강 데이터에서
  가설과 부합하는 유의미한 결과가 나오는지 더 세부적으로 정리 필요

**3. 종합 피드백**
- 발표 흐름이 매우 깔끔함. 가설 설정을 완벽하게 하고, 큰 틀에서 세부적으로
  깊이 있게 분석을 진행함

> 이 피드백 중 2번(고BMI+흡연 결합 효과를 더 세부적으로)이 실제로 반영된
> 결과가 `docs/03_issues_and_troubleshooting.md`의 **Issue 4**(가설 6 기각 →
> 가설 7 재설계, 상호작용항 회귀분석 도입)입니다.

## 서브 튜터 피드백 — 신재춘 튜터

**1. 데이터 EDA 및 전처리**
- 상관계수의 유의미한 범위를 미리 설정해 분석의 객관성을 확보하려는 시도가
  훌륭함

**2. 결과 해석 및 보고**
- 60대 이후 혈압 역전 현상에 대해 "연령 가중치"라는 대안적 해석을 제시하고,
  고BMI 집단과의 복합 작용을 심층 분석해 설득력을 높인 점이 훌륭함

**3. 종합 피드백**
- 가설 설정 → 전처리 → 상관관계 분석 → 최종 결론까지의 흐름이 체계적이며,
  시각화 자료의 가독성이 뛰어남

## KPT 회고

### Keep (잘한 점 / 유지하고 싶은 것)

**개인별**
- **이지아**: 어려운 과제였음에도 팀원 간 활발한 의사소통으로 과제 의도에
  부합하게 수행했다고 생각함
- **박재경**: 서로의 의견을 공유하며 방향성을 제대로 잡아갈 수 있었음
- **안영진**: 팀원들끼리 활발히 의견을 나누고 업무를 분담해 협업으로
  결과물을 만듦. 가설을 세우고 검증하는 과정에서 데이터를 가공·분석·시각화하며
  관련 역량을 기름
- **유지수**: 팀원들과 소통하며 분석 전 과정을 실시간으로 공유해 더 깊게
  분석하고 문제를 해결할 수 있었음. 흡연이 건강에 나쁠 것이라는 가설을
  다양한 시각화 자료로 입증함
- **이근주**: 서로의 의견을 적극 공유·반영하며 더 나은 방향으로 발전해감

**팀 전체**: 업무 분담을 통한 협업, 적극적인 소통

### Problem (아쉬웠던 점)

**개인별**
- **이지아**: 변수가 많은 바이오데이터의 전처리 방법에 대한 학습 필요.
  코딩 역량이 부족해 시각화 구현에 시간이 많이 소요됨
- **박재경**: 유의미한 가설 설정과 검증 방법에 대한 추가 학습 필요
- **안영진**: 데이터셋에 성별 데이터가 없고 고연령 데이터가 미흡해 양질의
  분석이 어려웠음
- **유지수**: 성별 데이터 부재, 다양한 전처리 방법을 알지 못해 아쉬움. 전
  과정을 함께 진행하다 보니 역할 분배가 크게 의미 없었음
- **이근주**: 남녀 데이터가 없어서 아쉬움

**팀 전체**: 성별·고연령 데이터 미흡, 시간 부족

### Try (다음에 시도해보고 싶은 것)

- 이상치 전처리 방법 추가 학습
- 결과 보고서 작성 시 전처리 부분에 더 비중을 두고 자세히 작성
- 더 다양한 데이터 분석 기법 시도

## 이 저장소 정리 과정에서 참고한 포인트

- 유지수 팀원이 남긴 "전 과정을 함께 진행하다 보니 역할 분배가 크게 의미
  없었다"는 회고는, `notebooks/team_final/`을 셀 단위로 특정 팀원에게
  귀속시키지 않고 "버전 A/B/C"로만 구분한 이유이기도 합니다 — 실제로 누가
  어떤 셀을 작성했는지 노트북 자체에는 기록이 없고, 팀원들의 회고도 협업이
  뒤섞여 있었다고 말하고 있어 개인별로 귀속시키는 것 자체가 사실과 다를
  가능성이 높다고 판단했습니다.
- 임영재 튜터의 피드백(고BMI+흡연 결합 효과를 더 세부적으로)은 `03_issues_and_troubleshooting.md`
  Issue 4의 직접적인 계기로 문서에 연결해두었습니다.
